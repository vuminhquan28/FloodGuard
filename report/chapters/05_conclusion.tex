\chapter{Kết Luận \& Hướng Phát Triển}

\section{Kết Quả Đạt Được}
Dự án \textbf{FloodGuard} đã hoàn thành đầy đủ các mục tiêu thiết kế ban đầu:
\begin{enumerate}
    \item Thiết kế và mô phỏng hoàn chỉnh hệ thống trên nền tảng Wokwi kết hợp vi điều khiển ESP32.
    \item Thuật toán FSM và dải trễ Hysteresis vận hành ổn định, loại bỏ triệt để hiện tượng rung giật đóng cắt thiết bị.
    \item Giao diện Web Dashboard trực quan, truyền nhận dữ liệu nhanh chóng qua Wi-Fi thời gian thực.
\end{enumerate}

\section{Hướng Phát Triển Trong Tương Lai}
\begin{itemize}
    \item Kết nối truyền thông qua giao thức MQTT và dịch vụ điện toán đám mây (AWS IoT Core / ThingsBoard).
    \item Tích hợp thuật toán học máy (Machine Learning) nhẹ để dự báo đỉnh triều cường và lưu lượng mưa trước 1--2 giờ.
    \item Trang bị thêm nguồn pin dự phòng (UPS/Solar) đảm bảo hệ thống không bị gián đoạn khi mất điện lưới do bão lũ.
\end{itemize}
